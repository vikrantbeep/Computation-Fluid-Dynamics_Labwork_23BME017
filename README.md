# Computational Fluid Dynamics Laboratory

This repository contains the experiments and assignments completed as part of the **Computational Fluid Dynamics (CFD)** elective course in my B.Tech Mechanical Engineering programme at PDEU.

The assignments involve numerical simulation and analysis of various fluid flow and heat transfer problems using Python.

**Tools Used:** Python, NumPy, Matplotlib, Jupyter Notebook and Google Colab.
